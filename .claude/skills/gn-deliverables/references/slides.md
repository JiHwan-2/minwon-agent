# 발표자료 (10장 이내, 별지 3) — 서류평가 20점, 본선 6분 + 질의 2분

규정 구간표: 문제 30초 → Agent 설명 1분 → 구조 1분 → **실제 시연 2분 30초(제출 영상)** → 성과 30초 → 발전계획·BM 30초. 규정은 "발표자료를 잘 만들기보다 시연 동선 리허설"을 권한다 → 글자는 적게, 그림·수치 위주.

## 만드는 법

1. `docs/submission/slides/구성.md`에 아래 10장 구성으로 장별 제목·핵심 문장·그림을 적고 사용자 확인.
2. `anthropic-skills:pptx` 스킬로 `docs/submission/slides/AI민원길잡이_발표.pptx` 생성 (16:9, 한글 글꼴 맑은 고딕 또는 Pretendard, 장당 핵심 문장 1개 + 그림/표 1개).
3. 7장(시연)은 제출 영상을 넣거나 링크. 화면 캡처는 실제 서비스에서.
