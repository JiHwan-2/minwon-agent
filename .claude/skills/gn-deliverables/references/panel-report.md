# 개발완료보고서 — 판넬형 (별지 4)

규정: A4 5페이지 이내(표지 제외) 또는 **판넬형 보고서를 이미지로 제출 가능**. 예시: `docs/reference/운영규정_별지4_판넬예시_1.png`, `_2.png` (만들기 전에 두 이미지를 다시 본다).
보고서는 문서 양이 아니라 **실제 구현과 신규개발분 확인용**(제22조). 제22조 필수 8요소를 모두 담아야 하므로 **판넬 1장(본문) + 판넬 2장(검증·신규개발분)** 으로 만든다.

## 예시 판넬의 구성 (그대로 따른다)

세로 한 장 포스터: **머리말**(작품명 큰 글씨·한 줄 소개·팀명·팀원) → **01 프로젝트 개요**(번호 매긴 문장 4개 + 오른쪽 인용 상자) → **02 개발 세부 내용**(왼쪽 1·2·3단계 상자, 오른쪽 시스템 구성도 5칸 흐름, 아래 '활용 데이터'·'활용 기술' 띠) → **03 구현 결과**(왼쪽 기능 체크리스트, 오른쪽 실제 화면 캡처 2개) → **04 기대 효과**(문단 + 작은 그림) → 바닥글.

## 판넬 2 내용 (재료)

- **테스트 결과**: TC1~TC8 표(유형·입력 요약·결과) — `docs/testcases.md` (기능이 크게 바뀌었으면 제출 전 `run_testcases.py`로 다시 돌린 결과)
- **평가 세트**: 담당 기관 정확도(경남 7개 시 11건, 3회 반복), 입력 확인·대화 판단(4개 언어), 흔들림 측정 — `docs/eval/README.md`. 한계(일부 문항을 개발 중에 사용)도 함께
- **신규개발분**: 날짜별 주요 개발(9/29 설계 → 10/1 골격·Tool·E2E → 10/2 판단 엔진·공공데이터·테스트·입력 확인 → 10/3 다국어·대화 → …) + "기존자산 없음, 전부 개발기간 중 이 저장소에서 작성" — `docs/sources.md`
- **출처 요약**: AI 도구(Claude Code: 코딩 보조·판단 엔진), 오픈소스(라이선스), API·데이터 — 출처신고서와 같은 내용 축약
- **한계·향후계획**: 지자체별 부서명 차이(일반 표현 사용), 판단 엔진 사용량·응답 시간, 번역 원어민 검토 없음, 사용자 검증 규모 → 지자체 조직도 연동, 사진 위치(진행 상황에 맞게), 기관 담당자 검증

## 화면 캡처 목록 (실제 서비스에서)

| 번호 | 화면 | 쓰는 곳 |
|---|---|---|
| S1 | 입력 + '처리 계획' 채팅 + 작업 기록 상단 | 판넬 1-03, 발표 5장 |
| S2 | 작업 기록: Tool 카드(카카오·공공데이터) + '초안 검증 → 다시 작성' | 판넬 1-03, 발표 5·6장 |
| S3 | 민원 패키지 카드(제출할 곳·창구 버튼·증빙 필수/권장·PDF 받기) | 판넬 1-03 |
| S4 | 베트남어 화면: 번역본과 '제출용 한국어로 보기' | 판넬 1-04 또는 2 |
| S5 | 민원 패키지 PDF 1쪽 | 판넬 2 |

캡처 방법: Chrome 개발자 도구 → 요소 오른쪽 클릭 → 'Capture node screenshot'(선명함) 또는 Win+Shift+S. `docs/submission/panel/img/`에 저장. 개인정보·키·로컬 경로가 보이지 않는지 확인.

## 만드는 법

1. 재료를 `docs/submission/panel/판넬.md`에 정리하고 사용자 확인 (문장은 판넬에 들어갈 길이로 짧게).
2. `docs/submission/panel/panel1.html`, `panel2.html`을 HTML/CSS 한 장으로 만든다: 1240×1754px(A4 세로 비율), 외부 의존 없이 이미지는 `img/` 상대 경로, 글꼴 Pretendard(웹폰트) 또는 맑은 고딕, 색은 서비스 기본색(#1d5bd6 계열)로 통일. 구역 제목에 01~04 번호, 예시처럼 둥근 카드·아이콘(이모지 또는 단순 SVG). 사진·캐릭터 이미지를 지어내지 않는다.
3. 미리보기: 브라우저 창으로 열어 확인 (필요하면 `docs/submission`을 간단한 정적 서버로 띄워 미리보기).
4. 뽑기 (사용자가 Chrome에서): **PNG** = 개발자 도구 → Ctrl+Shift+P → 'Capture full size screenshot'(장치 배율 2 권장) / **PDF** = Ctrl+P → 대상 'PDF로 저장', 여백 없음, 배경 그래픽 체크.
5. 결과 파일: `AI민원길잡이_개발완료보고서_판넬1.png`·`_판넬2.png` + 두 장을 묶은 PDF.

## 점검

- 제22조 8요소가 두 판넬 안에 모두 있는가 (위 배치 표로 하나씩 확인)
- 글자가 인쇄했을 때 읽히는 크기인가 (본문 14px 이상 @1240px 폭)
- Workflow ①~⑦·기능 이름이 기술설명서·발표자료와 같은가
- 수치·효과가 근거 파일과 일치하고, 측정하지 않은 것을 쓰지 않았는가
