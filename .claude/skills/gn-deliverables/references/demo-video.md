# 시연동영상 (3분, 별지 2) — 서류평가 40점, 본선 시연도 이 영상

규정: 3분 원칙(5분까지 가능하지만 본선 발표시간에 포함), **홍보영상처럼 편집하지 말고 실제 입력 → Agent 판단 → Tool/API 호출 → 결과**가 보이게. 심사위원은 분량보다 실제 동작 증거를 본다. **기술설명서와의 연결성**이 중요 → 화면 위 자막에 Workflow ①~⑦ 번호를 띄운다.

## 화면 구성

- 브라우저 한 창에 **왼쪽 대화 + 오른쪽 Agent 작업 기록**이 함께 보이게 (가로 1920px 이상, 확대 110~125%). 작업 기록의 '판단 엔진: AI 판단', Tool 카드(카카오 API·공공데이터 API), '초안 검증 → 다시 작성'이 읽혀야 한다.
- 머리말의 '판단 엔진 · claude-opus-5-5 (Claude Code)' 표시가 첫 장면에 보이게.
- 개인정보·API 키·바탕화면·다른 탭이 나오지 않게 (브라우저 전체 화면 F11 권장).

## 3분 대본 (권장)

교육자료 D6 구성(0:00 문제 → 0:30 입력 → 1:00 자동 실행 → 2:20 결과와 효과)과 "시연은 변화의 증명: **Before → Input → Agent → Output → After**"를 따른다.

| 시간 | 화면 | 자막·내레이션 | 보여 줄 Agent 요소 |
|---|---|---|---|
| 0:00–0:30 | **Before** 제목 카드 1~2장 | 누구의 어떤 문제인지: 위험한 횡단보도를 신고하려 해도 어느 기관·창구에, 무엇을 준비해 내야 할지 모름 (기존 방식의 단계를 글로 설명. 측정하지 않은 시간 수치는 쓰지 않음) + 작품명 | 문제 |
| 0:30–0:40 | **Input**: 입력 "학교 앞 횡단보도가 너무 위험해요." | ① 입력·안전 점검 | Goal |
| 0:40–1:00 | 채팅 '문제로 이해했어요' + '처리 계획' 목록, 작업 기록 카드 | ② 입력 확인·문제 분석 → ③ 처리 계획 | Planning |
| 1:00–1:20 | Agent가 위치·시간을 질문 → 시민이 답 입력 (예: 김해시 삼계동 삼계초등학교 정문 앞, 평일 아침 등교 시간) | ④ 정보 판단·추가 질문 | Reasoning, Memory |
| 1:20–1:50 | 작업 기록의 Tool 카드: 카카오 위치·관할 경찰서·지식베이스·공공데이터 사례 | ⑤ Tool 실행 (실제 API 호출) | Tool Use |
| 1:50–2:20 | 담당 기관 판단 → 초안 작성 → **초안 검증이 문제를 찾아 다시 작성** | ⑥ 판단·작성·검증 | Feedback |
| 2:20–2:40 | **Output**: 민원 패키지 — 제출할 곳·창구 버튼·할 일·초안·증빙(필수/권장, 근거)·PDF 받기 | ⑦ 결과 전달 (제출은 시민이 직접) | 결과 |
| 2:40–2:52 | 짧은 장면 1~2개: ⓐ 베트남어 입력 → 번역본 ↔ 제출용 한국어 원문 전환 ⓑ "기모띠" 같은 엉뚱한 말 → 민원으로 가지 않고 대화로 답함 (또는 위기 표현 → 109 안내) | 다국어·안전장치 | 차별성·안전 |
| 2:52–3:00 | **After** 성과 카드 | 테스트케이스·평가 세트 수치(최신 실행 기준). 사용자 검증·시간 단축은 측정했을 때만 | 성과 |

- 시나리오 근거: TC2(부정확한 입력)가 질문 → 답 → 검증 재작성까지 한 번에 보여 준다 (`docs/testcases.md`). 담당 기관 정확도는 `docs/eval/` 기준.
- **검증 단계의 '다시 작성'은 매번 일어나지 않는다.** 같은 시나리오를 여러 번 녹화해 실제로 다시 쓴 회차를 고른다(조작이 아니라 실제 실행 중 선택). 끝내 안 나오면 '검증 통과' 장면으로 쓰고 다시 쓰기는 작업 기록 캡처(실제 실행 기록)로 설명한다.
- ⓐⓑ는 시간이 모자라면 하나만.

## 녹화 전 점검

- 백엔드·프론트 최신 `main`으로 재시작, `/api/health`에서 `claude_code`·카카오·공공데이터가 모두 켜졌는지
- **Claude 사용량 한도**: 녹화 직전에 무거운 작업(평가 반복 실행 등)을 하지 않는다. 한도에 걸리면 작업 기록에 '대체 경로'가 뜬다 → 그 회차는 버린다
- 브라우저 확대·창 크기 고정, 화면 언어 한국어, 이전 대화는 '새 민원'으로 비움
- 녹화본을 처음부터 끝까지 다시 보고, 작업 기록의 판단 엔진 표시가 'AI 판단'인지(규칙 대체가 없는지) 확인
