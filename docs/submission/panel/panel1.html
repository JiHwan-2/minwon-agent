01

프로젝트 개요

개발 배경 · 목표
  1. 1가로등 고장, 위험한 횡단보도 같은 생활불편을 겪어도 어느 기관·창구에 무엇을 준비해 내야 할지 몰라 민원을 포기하거나 잘못 낸다.
  2. 2행정 용어·절차가 낯선 시민, 한국어가 서툰 경남 거주 외국인 주민에게는 더 어렵다.
  3. 3AI Agent가 시민의 말·현장 사진을 이해하고, 모자란 정보는 묻고, 지도·지식베이스·공공데이터로 근거를 찾아, 담당 기관과 민원 초안을 스스로 검증해 건네는 것이 목표다.
  4. 48일 개발기간 동안 입력부터 민원 패키지(PDF)까지 처음부터 끝까지 동작하는 MVP(Level 3)를 완성했다. 민원 제출은 시민이 확인 후 직접 한다.
시민의 말을 민원으로 바꾸는 행정 길잡이

스스로 계획하고, 모자란 정보는 묻고, 검색으로 근거를 찾고,
결과를 검증한 뒤 건넨다
