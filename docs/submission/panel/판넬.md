# 개발완료보고서 (판넬형) — 근거와 만드는 법

제출 파일: `AI민원길잡이_개발완료보고서_판넬1.png`, `_판넬2.png` (각 3508×2480, A4 가로 비율) + 두 장을 묶은 `AI민원길잡이_개발완료보고서.pdf` (2쪽).
판넬 1은 예시처럼 01 개요 ~ 04 기대 효과(8요소를 짧게 모두 포함), 판넬 2는 제22조가 강조하는 테스트·신규개발분·성과·한계의 상세 증거 (팀장 결정 2026-10-05: 한 장으로 줄였다가 2장으로 되돌림). 결과 파일은 git에 올리지 않고 대회 사이트로 따로 제출한다.

## 다시 만드는 법 (저장소 폴더, PowerShell)

화면 캡처를 새로 찍을 때 (서버·화면을 켠 상태, 실제 Claude 사용):
```bash
backend\.venv\Scripts\python docs\submission\capture_screens.py --only traffic,vi,service
```
판넬 HTML을 PNG·PDF로 뽑을 때 (넘친 칸이 있으면 알려 줌):
```bash
backend\.venv\Scripts\python docs\submission\panel\render.py
```
내용은 `panel1.html`·`panel2.html`, 모양은 `panel.css`에서 고친다. 화면 조각(`img/p_*.png`)은 실제 캡처(`img/traffic_*`, `vi_*`, `service_*`)에서 잘라 낸 것이다.
