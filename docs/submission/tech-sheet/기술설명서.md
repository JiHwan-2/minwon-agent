# AI Agent 기술설명서 (별지 1, 1페이지)

근거: `docs/design.md`(구조·기능·Tool·안전장치), `docs/testcases.md`(6차, 10/4), `docs/eval/README.md`(10/4), `docs/sources.md`. 수치는 2026-10-04 기준.
Workflow ①~⑦ 이름은 `gn-deliverables` 스킬의 공통 표와 같다 (판넬·영상·발표자료와 같은 이름). 1페이지를 넘기지 않도록 문장을 줄였다 (표 항목은 별지 1 그대로).
Word 파일은 이 표에서 만든다: `AI민원길잡이_기술설명서.docx` → Word에서 PDF로 내보냄.

| 항목 | 기재 내용 |
|---|---|
| 팀명 / 부문 / 주제 | AI민원길잡이 / 대학부 / 01 사회문제 해결형 AI Agent |
| 작품명 | AI민원길잡이 — 생활불편을 말하면 담당 기관을 찾고 민원 준비를 돕는 행정 길잡이 AI Agent |
| 해결 문제 | 위험한 횡단보도·고장 난 가로등·소음 같은 생활불편을 겪어도 담당 기관·제출 창구·증빙을 몰라 민원을 포기하거나 잘못 내는 문제. 외국인 주민은 언어·절차 장벽이 더 큼 |
| 대상사용자 | 행정 절차에 익숙하지 않은 시민(대학생·어르신 보호자 등), 경남 거주 외국인 주민(영어·중국어·베트남어) |
| Agent Goal | 시민의 말·현장 사진에서 문제·위치를 파악하고, 지도·지식베이스·공공데이터로 관할 기관과 절차를 찾아 스스로 검증한 민원 초안·증빙 목록·PDF를 준비 (서류 발급·신고는 지금 가능한 방법 안내). 제출은 시민이 직접 |
| 사용 AI/LLM/모델 | Claude Opus 5.5 (Anthropic)를 Claude Code CLI(`claude -p`)로 단계마다 실행, 단계별 지시문 + JSON Schema로 출력 형식 강제. 입력 확인·분석·계획·정보 판단·기관 판단·초안 작성·AI 검토·번역·대화·사진 분석에 사용. 로그인 계정으로 실행(LLM API 키 미사용) |
| 사용 Tool/API/Data/장비 | 카카오 로컬 API(장소·주소 검색, 행정구역, 주변 경찰서·행정복지센터·무인민원발급기) · 공공데이터포털 국민권익위 민원 질의응답(비슷한 사례)·행안부 무인민원발급기정보(운영시간) · 지식베이스(팀 작성: 생활불편 12유형 부서·창구·절차·증빙, 민원 서비스 17종, 다른 창구 4종, 공휴일) · 사진 정보(EXIF GPS) · PDF(fpdf2) · LangGraph·FastAPI·React |
| Memory/State/ Feedback 구현 | **Memory**: LangGraph 체크포인터에 대화·확인된 정보·질문 횟수·위치 후보·초안 버전 저장, 질문에서 멈췄다가(interrupt) 시민의 답으로 이어 감 · **Feedback**: 규칙 검사(연락처·개인정보·위치·근거 없는 '필수'·분량) + AI 검토 → 문제면 스스로 다시 작성(최대 2회), Tool 실패 시 재시도·대체 경로, 수정 요청 반영(따를 수 없으면 이유 안내), 중단 시 직전 상태 복원 |
| 핵심 Workflow (End-to-End 동작시나리오) | ① **입력·안전 점검**: 평소 말투·현장 사진 입력 → 개인정보 가림, 112·119·109 안내, 지시 주입 감지 ② **입력 확인·문제 분석**: Claude가 민원/민원 서비스/다른 창구/불분명/민원 아님과 유형·긴급도·언어를 판단 ③ **처리 계획**: 할 일·사용할 Tool을 계획해 화면에 표시 ④ **정보 판단·추가 질문**: 빠진 위치·상황을 묻고 답으로 이어 감 ⑤ **Tool 실행**: 카카오(위치·관할 기관)·지식베이스(부서·절차·증빙)·공공데이터(비슷한 사례) ⑥ **판단·작성·검증**: 담당 기관·창구 판단 → 초안·증빙 작성 → 규칙 검사 + AI 검토로 스스로 고쳐 씀 ⑦ **결과 전달·피드백**: 민원 패키지·PDF(외국인은 번역본 + 한국어 원문), 수정 요청 반영, 시민이 직접 제출 |
| 핵심기능 3~5개 | 1) 입력 확인·문제 분석·처리 계획 2) 추가 질문·대화(현장 사진 확인) 3) 위치·기관 검색 4) 담당 기관·절차 + 민원 패키지 PDF / 민원 서비스 안내 5) 결과 검증·수정 (공통: 4개 언어, 개인정보 가림·긴급·위기 안내) |
| 기존자산/ 8일 신규개발분 | **기존자산**: 없음 (공개 오픈소스·API만 사용, 목록은 출처신고서) · **8일 신규개발**: 모든 코드·지식베이스·화면·평가 세트를 2026-09-29~10-06에 이 저장소에서 작성 (커밋 기록, `docs/sources.md`) |
| 대표 테스트 5건 결과 | **9건 모두 통과** (10/4, 실제 Claude·카카오·공공데이터): TC1 정상 입력 → 담당 기관·PDF / TC2 부정확한 입력 → 위치 질문 후 진행, 검증이 고쳐 씀 / TC3 데이터 없음 → 일반 안내 + 국민신문고 / TC4 API 오류 → 대체 경로로 완성 / TC5 악의적 입력 → 개인정보 가림·지시 주입 감지 / TC6~9 수정 요청·민원 종류 변경·처리 중단·민원 서비스 평가 세트: 입력 확인 132/132 · 담당 기관 11/11 · 민원 서비스 10/10 · 수정 요청 20/20 |
